# Samples

Two songs generated by YuE2 Studio's Swift/MLX code (`yue2cli`, the same pipeline the app runs) on an
Apple M5 Max Mac with the 8-bit weights, planning Full, 32 flow steps, CFG auto. Nothing was edited after
generation. Each was the better of two seeds by lyric error and melody match. All numbers are n=1; the full
set is in each folder's `stats.json`.

Click a title to play it in the browser (MP3, VBR ~230 kbit/s). Each folder also has `song.m4a` (AAC 256 kbit/s,
with title and cover art) for downloading.

How to read these:
- **Scoring.** Lyric error is Qwen3-ASR-1.7B on the Mel-RoFormer vocal stem, compared with the lyrics. Melody
  and chord match compare SheetSage2's transcription of the audio with the score the model planned; chance
  melody match is about 0.30.
- **Sung an octave below the written score.** Both songs show it. Every YuE2 plan we measured does the same
  (see the main README).
- **The planner ignored the requested tempo** on the ragtime song.
- **On devices** the same pipeline takes about 7 minutes for a full song on an M5 iPad Pro (8-bit) and about
  9 minutes on an iPhone 18 Pro (4-bit, low-memory mode).

Each folder also has `style.txt` and `lyrics.txt` (the exact inputs) and `score.abc`, the score the model wrote
and then sang. To hear a variation of the same song, paste the score into the app's score box with planning on
Full and change the seed.
